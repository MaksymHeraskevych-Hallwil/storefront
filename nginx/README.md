# nginx

Єдина точка входу ззовні (порт 80). Проксіює `/api/*` на `backend` (з `client_max_body_size 6m` для
завантаження зображень), `/media/*` — на MinIO (лише читання), решту — на `frontend`;
корінь `/` теж туди тимчасово, поки на Етапі 3 не з'явиться `frontend` —
тоді `/` перемкнеться на нього, а `/api/*` лишиться на бекенді.

HTTPS і Cloudflare — за зразком `my-blog/nginx` — пізніший етап.
